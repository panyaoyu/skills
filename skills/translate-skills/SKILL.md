中英文目录按相对路径一一对应，目录位置从当前仓库的 `AGENTS.md` 读取（未配置时向用户确认）。

1. 读取[中英双向术语表](references/translation-terms.md)。

2. 对比两侧从 `HEAD` 到工作区的变更（含未跟踪的新文件），找出变化的文件、待同步的段落。按用户指定的方向翻译；未指定时，以改动的一侧为原文。

3. 翻译待同步部分。已存在的文件只更新对应变更处，新增文件整篇翻译：
   - 按目标语言的技术写作习惯表达每个语义单元。
   - 按术语表选词。保留代码和公式，只翻译其中面向读者的自然语言说明。
   - Markdown 结构与原文一一对应：标题层级、列表项数、表格行列数、链接目标。

4. 对照原文核实本次译文，确认信息无增删且符合第 3 步要求；有问题时整句重写。

5. 在本次改动的原文范围内检查术语，发现以下情况时向用户报告位置与建议，待用户确认后再修改术语表或原文：
   - 符合术语表收录标准的新词（附推荐译法与禁用译法）。
   - 使用了术语表中该概念在原文语言里应避免的说法，或同一概念前后用词不一致。
