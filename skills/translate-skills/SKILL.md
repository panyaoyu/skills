name: translate-skills
description: 将中文 skill 的改动同步翻译到对应的英文版
---

中文源目录与英文目标目录按相对路径一一对应，目录位置从当前仓库的 `AGENTS.md` 读取（未配置时向用户确认）。

1. 读取本技能目录下的 `references/translation-terms.md`。

2. 找出待同步的改动。对比中文版与英文版从 `HEAD` 到工作区的变更（含未跟踪的新文件），列出中文版已改动或新增、而英文版尚未同步的文件与段落。

3. 翻译待同步部分。已存在的文件只更新对应变更处，新增文件整篇翻译：
   - 阅读一个语义单元后，以英语母语技术作者的习惯重新组织句式。
   - 每个术语都遵循对照表，每个代码片段/公式都原样保留（若其中有中文，需要翻译）。
   - Markdown 结构与原文一一对应：标题层级、列表项数、表格行列数、链接目标。

4. 对照中文原文核实本次改动的译文，确认原文每句信息均已译出、无增删，且符合第 3 步各项要求；有问题时整句重写。

5. 在本次改动的中文范围内检查术语，发现以下情况时向用户报告位置与建议，待用户确认后再修改对照表或中文版：
   - 符合对照表收录标准的新词（附推荐译法与禁用译法）。
   - 使用了对照表「中文不要用」列中的说法，或同一概念在中文里前后用词不一致。
