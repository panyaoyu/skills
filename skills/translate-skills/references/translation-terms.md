# 中译英翻译对照表

把 skill 从中文版翻译成英文版时，表中的中文词一律译作「English」列的写法。

- 「不要译作」：明确禁用的英文译法。
- 「中文不要用」：同一个概念在中文里不使用的其他说法。翻译时遇到这些说法，按同一行的「English」翻译。
- 「备注」：使用条件或概念边界。

只收译法不固定会造成误解的词：同一个概念用了不同译法，读者可能以为是不同的东西；或者一个译法容易和另一个概念混淆。化工标准术语和普通词不收。
